# VANTIX Downloads

This repository contains approved public VANTIX installer releases and checksums.
It does not contain the private VANTIX source code.

Read each release's signing status and release notes before installing. Verify the
downloaded file's SHA-256 against its checksum and public release manifest.

Windows preview installers labeled unsigned have no trusted publisher signature.
Mac preview installers labeled ad-hoc are not Developer ID signed or notarized.
Do not disable operating-system protections to install a preview.

Android and iOS are Coming Soon. Installer releases do not enable automatic
launcher updates.
